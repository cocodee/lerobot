# LeRobot 系统架构文档

## 1. 项目概述

**LeRobot** 是由 Hugging Face 开发的面向真实世界机器人的机器学习框架，提供 PyTorch 实现的模型、数据集和工具，专注于模仿学习（Imitation Learning）和强化学习（Reinforcement Learning）。

> **当前分支**: `hil-webxr-rot-cc` - 定制分支，包含 WebXR 遥操作支持和 HIL-SERL（Human-in-the-Loop SERL）集成

## 4. 核心模块详解

### 4.1 遥操作模块 (`teleoperators/`)

| 文件/目录 | 功能描述 |
|-----------|----------|
| `teleoperator.py` | 遥操作基类，定义通用接口 |
| `webxr/` | WebXR/VR 遥操作接口，支持 HTTP 通信 |
| `so100_leader/` | SO-100 主臂（Leader）控制 |
| `so101_leader/` | SO-101 主臂控制 |
| `bi_so100_leader/` | 双臂 SO-100 主臂控制 |
| `supre_robot_leader/` | Supre 机器人主臂（自定义双臂系统） |
| `ros2_leader/` | ROS2 主臂接口 |
| `gamepad/` | 游戏手柄控制 |
| `keyboard/` | 键盘控制 |

### 4.2 机器人模块 (`robots/`)

| 文件/目录 | 功能描述 |
|-----------|----------|
| `robot.py` | 机器人基类，抽象接口定义 |
| `so100_follower/` | SO-100 从臂（Follower）实现 |
| `so101_follower/` | SO-101 从臂实现 |
| `bi_so100_follower/` | 双臂 SO-100 从臂 |
| `koch_follower/` | Koch 机器人从臂 |
| `hope_jr/` | HopeJR 人形机器人 |
| `lekiwi/` | 移动机器人平台 |
| `supre_robot_follower/` | Supre 机器人从臂（自定义双臂系统） |
| `ros2_follower/` | ROS2 从臂接口 |
| `sim_robot_panda/` | Panda 仿真机器人（支持 WebXR） |

### 4.3 策略模块 (`policies/`)

| 文件/目录 | 功能描述 |
|-----------|----------|
| `factory.py` | 策略工厂，用于创建策略实例 |
| `act/` | **ACT** (Action Chunking Transformer) - ALOHA 论文实现 |
| `diffusion/` | **Diffusion Policy** - 视觉运动学习的扩散策略 |
| `tdmpc/` | **TDMPC** - 模型预测控制的时间差分学习 |
| `vqbet/` | **VQ-BeT** - 基于离散潜在动作的行为生成 |
| `pi0/` | **PI0** - 视觉-语言-动作模型 |
| `pi0fast/` | **PI0 Fast** - PI0 快速变体 |
| `smolvla/` | **SmolVLA** - 轻量级 VLA 模型 |
| `sac/` | **SAC** - 软演员-评论家（强化学习） |

### 4.4 相机模块 (`cameras/`)

| 文件/目录 | 功能描述 |
|-----------|----------|
| `camera.py` | 相机基类接口 |
| `opencv/` | OpenCV 相机支持 |
| `realsense/` | Intel RealSense 相机支持 |
| `nv_opencv/` | NVidia 优化的 OpenCV 相机 |

### 4.5 数据集模块 (`datasets/`)

| 文件/目录 | 功能描述 |
|-----------|----------|
| `lerobot_dataset.py` | LeRobotDataset 主类，数据集格式实现 |
| `transforms.py` | 数据变换和增强 |
| `video_utils.py` | 视频编解码工具 |
| `push_dataset_to_hub/` | 上传数据集到 Hugging Face Hub 的脚本 |

### 4.6 模型模块 (`model/`)

包含神经网络组件：
- 视觉编码器（Vision Encoders）
- 动作头（Action Heads）
- 变换器架构（Transformer Architectures）
- VAE 组件

### 4.7 电机模块 (`motors/`)

| 文件/目录 | 功能描述 |
|-----------|----------|
| `dynamixel/` | Dynamixel 电机驱动（Robotis） |
| `feetech/` | Feetech 电机驱动 |
| `eyou/` | EYou 电机驱动 |

### 4.8 脚本模块 (`scripts/`)

| 文件 | 功能描述 |
|------|----------|
| `train.py` | 策略训练脚本 |
| `eval.py` | 策略评估脚本 |
| `teleoperate_webxr_panda.py` | Panda 的 WebXR 遥操作 |
| `rl/` | 强化学习相关脚本 |
| `server/` | 策略服务器（异步推理） |

## 6. 入口点与命令

| 命令 | 对应文件 | 功能 |

| `python -m lerobot.replay` | `replay.py` | 回放数据 |

| `python -m lerobot.scripts.eval` | `scripts/eval.py` | 评估策略 |

## 9. 项目特色功能

1. **WebXR 遥操作** - 支持 VR/HTTP 的远程控制接口
2. **HIL-SERL 集成** - Human-in-the-Loop 强化学习
3. **多机器人支持** - SO100/101、Koch、Aloha、Supre Robot 等
4. **异步推理** - 基于 gRPC 的策略服务器
5. **HuggingFace 生态** - 数据集和模型 Hub 集成
6. **ROS2 支持** - 完整的 ROS2 接口层
